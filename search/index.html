Search

Search is provided by Pagefind, a fully static search library with no server and no tracking. After the site is built, run npm run search:index to generate the search index from the built pages.

The hidden unlinked folder is excluded from search: its pages carry data-pagefind-ignore and are not in the sitemap. The in-progress page is excluded from the sitemap and is not a published investigation.

If the search index has not been generated yet, use the investigations index and the archive to browse published work.
