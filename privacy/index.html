Privacy Policy — EPCS Hermes Read-Only

Effective date: 15 November 2026.

This page describes the privacy practices of the EPCS Hermes Read-Only application. The application is a private, single-operator tool. It is not offered to the public, and it has no other users.

What the application does

The application reads the operator's own Google Sheets and Google Drive files, using read-only access, to maintain property-preservation records. It runs on the operator's own computers. It does not write to, delete, move, or share any Google data.

Data access

The application uses exactly two Google permissions, both read-only: reading spreadsheet values, and reading Drive files. It requests no Gmail access, no write access, and no access to any other person's account.

Data collection and sharing

The application collects no data from any visitor or third party. It sends no data to any third party, runs no advertising, and contains no analytics. Authorization tokens are stored only on the operator's own computers, and the operator can revoke the application's access at any time from Google Account permissions.

Changes

If this policy changes, the new effective date will appear at the top of this page.

Contact

Questions about this policy: insightgaps@gmail.com.
