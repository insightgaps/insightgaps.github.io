# Insight Gaps Documentation

This folder contains non-publication operating documents, planning notes, audits, and implementation records.

## Files

- `WEBSITE_BLUEPRINT.md` - working blueprint for the website structure, audience, page responsibilities, and publishing guardrails.

## Folders

- `governance/` - required architecture, schema, design, page, template, and AI workflow rules for all future agents.
- `publication/` - investigation-specific implementation reports, asset inventories, release checklists, and website upgrade plans.

## Placement Rules

- Keep live website pages in the root, `content/`, or `analysis/` according to `docs/governance/03-content-architecture.md`.
- Keep root governance entry points at `START_HERE.md` and `AGENTS.md`.
- Keep Antigravity-specific entry instructions at `ANTIGRAVITY.md`.
- Keep detailed governance files in `docs/governance/`.
- Keep public data in `data/`.
- Keep scripts in `methods/`.
- Keep planning and review artifacts in `docs/`.
- Do not store temporary QA screenshots at the repository root.
