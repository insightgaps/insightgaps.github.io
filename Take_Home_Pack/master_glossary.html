Master Domain Glossary: The Language of the Machine

"In mortgage default servicing, casual words create legal disasters. If you call an uninspected home 'vacant,' you risk a trespass lawsuit. If you call a field proposal an 'invoice,' you corrupt the accounting staircase. Master the vocabulary that protects the house and the company."

KEY POINT 1 • FOUNDATIONAL INSTITUTIONS

FHA Insures, Never Lends; Loss Mit First

FHA (1934): Insures private mortgages; never lends money. GI Bill (1944): 13.9M loans guaranteed (1944–1993). CFPB Reg X: 120-day pre-foreclosure evaluation floor—help precedes penalty. Securitisation: Pooling loans into mortgage-backed securities (MBS). Conveyance: Transferring cleared home to insuring agency.

KEY POINT 2 • OPERATIONAL SEPARATIONS

PPW Is Not the Portal; Gross Equals Net

PPW Engine: Internal prep, tagging, and CY math. Client Portal: External client submission (Equator, Aspen Grove, P260). Gross = Net: No arbitrary client discount. RFO Gate: Processor preps to ready; Approver marks RFO personally. Address Matching: Always link orders by property address, not order number alone.

KEY POINT 3 • STATUTORY FORECLOSURE ROAD

Default Has an Order: Do Not Reorder It

Default → Loss Mitigation First → State Foreclosure → Auction → REO / HUD Home. State foreclosure is judicial or non-judicial by state law. If no bidder tops credit bid at auction, title reverts to bank-owned (REO) or conveys to HUD as a HUD Home. A filing is not a start; a start is not an REO; an REO is not a work order.
