Demo — Photo QC Board

DEMO — all data is fake, for class/training only, not a real work system, do not submit anything here.

Judge every set with the Proof Test: PLACE (is this the right property and the right area?) · TIME (is it datestamped by the receiving system's rule?) · SCOPE (does it show the scoped work?) · CLARITY (can a reviewer actually see it?). A set fails if ANY leg fails. No photo descriptions below are real photographs — they are written sample descriptions for teaching.

QC rules this board teaches (FAKE examples, real discipline)

  • Flag every photo to exactly one set: Before, During, or After. An unflagged photo proves nothing, because no reviewer can find it in the right place.
  • Check the datestamp rule for the receiving system BEFORE field work, not after. In this demo the sample rule is date-only; other systems differ — the discipline is checking, not assuming.
  • One photo, one flagging action, verified after each action. Batch-flagging without verifying is how a whole set ends up in the wrong bucket.
  • A rejected set is fixed in the file (retake, re-flag, re-datestamp), then re-checked. The submission step, when it happens in a real system, happens only after owner cross-check and only on the owner's word — and it never happens in this demo.
