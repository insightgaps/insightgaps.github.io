Auto-Bid Property Audit Monitor (FAKE)

The real system's best demo idea, kept and made explicit here: for each property, the monitor cross-references approved-bid history and flags newly found hazards for a pre-draft bid. In this demo:

  • SAMPLE-004: debris removal held for a proof gap ⇒ no new bid is drafted until the gap is cured. A bid built on a failed file is not a bid, it is a rejection waiting to happen.
  • SAMPLE-008: recurring recut ⇒ next-cycle bid pre-drafted from the prior cycle's approved history, staged only, never submitted in this demo.
