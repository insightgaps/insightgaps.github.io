Demo — Losses, reason codes, disputes

DEMO — all data is fake, for class/training only, not a real work system, do not submit anything here.

Every loss in the real system carries a mandatory reason code. UNEXPLAINED is a working queue, driven to zero by checking the invoice part of the order and by portal mining — never a resting state, never a closed book.

Reason-code taxonomy (demo)

PHOTO_QC / WORK_QUALITY / LATE / PRICE_ADJUSTMENT / ALLOWABLE_CAP / PAID_VIA_SUCCESSOR / CLIENT_ERROR / UNEXPLAINED, plus free-text evidence and source (sheet remark / portal / proof). In this demo:

$0 sample with no reason UNEXPLAINED queue = $0 in this sample set That is the point: the queue is driven to zero, and $0 here means the sample set was coded, not that real losses have no reasons

What the reasons teach, in the real system: photo/QC insufficient is the top stated cause — that feeds photo standards and crew training. Late performance/submission cuts feed timeline discipline. Work-not-proper feeds quality handling, not mystery deductions. Loss-by-reason is how losses get PREVENTED, not just explained.

Chain-paid, not unpaid (FAKE)

No "unpaid" classification is final until the chain check runs (see Property Master). A sample order paid under a follow-up number at the same property is filed as PAID_VIA_SUCCESSOR, with the successor order and paid amount as evidence, and leaves ageing/loss views into an "explained unpaid" bucket.

Deduction evidence packs and dispute windows (FAKE)

A chargeback without a client reference + reason code + evidence is disputable by construction. In this demo, a dispute pack is assembled from: photos, job notes, and proof of completion — the same file the Photo QC board judges. Disputes are a workflow with deadlines (sample windows shown as teaching windows, not real client windows — real windows come from the client, never from this demo). The adjustment queue gains a per-client dispute window, and the pack is auto-assembled in a real system; in this demo, the pack contents are listed, not sent anywhere.
