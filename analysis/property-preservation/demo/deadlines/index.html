Demo — Deadlines and Pulse: today in the field

DEMO — all data is fake, for class/training only, not a real work system, do not submit anything here.

Every dated obligation in the real system becomes a deadline record: order due dates, bid approvals, recurring recuts, invoice windows. This demo shows the same engine, with the same escalation, on the same fake orders.

Escalation rule (demo, same as the real system)

  • Silent until T-48 hours.
  • Surfaces in the digest at T-24 hours.
  • Direct flag at T-4 hours if still open.
  • An open follow-up on an order is a payment-risk flag from the day it appears — pay is not earned until follow-ups are cured.

Overdue view (FAKE, teaching only)

In this demo story, no sample order is shown as overdue, because the teaching point is the escalation, not a panic list. If a sample order were overdue, it would appear here, in red in a real system, with its age, its owner, and its next action — and it would stay here until its state changed or a recorded adjustment closed it. There is no "dismiss" in this demo: an item closes only by a state change or a recorded decision.

What this page mirrors in the real system

Deadline Engine (v2 M3) + Pulse / Command Board: due-state + crew schedules on one "today in the field" board, silent unless something changed, digest on deltas, not on schedule noise.
