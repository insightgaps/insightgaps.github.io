Demo — Guided Tour (10 minutes)

DEMO — all data is fake, for class/training only, not a real work system, do not submit anything here.

This tour is the fastest way to learn the demo. Follow it in order, in class or alone. Each stop says what to look at and what "good" looks like. Nothing here submits, sends, or records anything.

Stop 1 — Live Ops: what is happening right now (2 minutes)

Open Live Ops — FAKE. Read the table by STATE, not by order number.

  • Count the states out loud: In Field 2 · Unassigned 2 · Completed — Awaiting Owner Cross-Check 2 · Held/Blocked 2. Total 8.
  • The lesson: "Completed" here means completed in the field, awaiting owner cross-check. It does NOT mean submitted, approved, or paid. If a learner calls a cross-check order "done", stop them — that is the exact mistake the submission discipline exists to prevent.

Stop 2 — Properties: one property, one record (1 minute)

Open Properties — FAKE. Use browser find (Ctrl+F / Cmd+F) and search for "101 Sample Lane".

  • Note the key: SAMPLE-001, keyed by ADDRESS. A renumbered order at the same address is the same job, not a new property.
  • Chain check, said out loud: no "unpaid" label on an earlier order at an address is final until the follow-up orders at that same address have been checked.

Stop 3 — A single order, end to end (3 minutes)

Open Work-Order Example — FAKE. This is WO-EXAMPLE-003, a $120 sample winterization at SAMPLE-003, followed from intake to owner cross-check.

  • Follow the timeline: intake → field → photos → QC → money → cross-check.
  • Then read the contrast box: WO-EXAMPLE-004, $250 sample debris removal, HELD for a proof gap. Ask: what is missing, and what is the next action? The answer is never "submit it anyway".

Stop 4 — Photo QC: does the file prove the work? (2 minutes)

Open Photo QC — FAKE. Use the Proof Test: PLACE / TIME / SCOPE / CLARITY.

  • One set passes, one set fails on a datestamp, one set is still in the field and cannot be judged yet. Learners must sort them, not guess them.
  • The datestamp rule in this demo: check the receiving system's rule first. Never assume one rule fits every system.

Stop 5 — Money and the Meeting Brief (2 minutes)

Open Money — FAKE, then Meeting Brief — FAKE.

  • Money: follow the ladder — claimed $1,200 → approved $1,000 → invoiced $1,000 → paid $750 → outstanding $250. All sample, gross = net, no discount.
  • Loss discipline: the only sample loss ($50) carries a reason code (SAMPLE-REASON-01). Unexplained is $0 in this set — and that is the point. An unexplained loss is a queue driven to zero, never a closed book.
  • Meeting Brief: every number there is computed from the demo tables. If a number cannot be traced to a table, it does not belong in a brief.
