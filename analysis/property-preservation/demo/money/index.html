Loss-reason discipline (demo)

Every loss in a real system carries a mandatory reason code. In this demo, the only sample loss ($50) carries SAMPLE-REASON-01. A loss without a reason is recorded as UNEXPLAINED, in the queue, with owner and date — never invent a reason to close it, and never call an unverified deduction a "client deduction" until it is verified.
