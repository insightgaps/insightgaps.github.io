Demo — Growth: onboarding pipeline

DEMO — all data is fake, for class/training only, not a real work system, do not submit anything here.

The real system gained a Growth part alongside operations: a vendor onboarding pipeline, a target map, and a revenue-conversion stage. This demo shows that part in structure only — no application, no outreach, and no commitment is made in this demo, and none can be made from it.

Target map, structure only (FAKE)

In a real system, the target map ranks warm paths, flags title discrepancies, and keeps prospects, offers, outreach, metrics, and outcomes separate between pipelines. In this demo, the map is shown as empty structure only: Sample Prospect 1, Sample Prospect 2, Sample Prospect 3 — no real person, no real company, no real contact, no real message. A target map with real names in it would be a leak, not a demo.

Revenue-conversion stage (FAKE)

First order → margin → repeat. A first order that loses money at the sample price is a Reprice decision (see Client Economics), not a growth win. Growth that is bought by losing margin is not growth in this demo's teaching rule.
