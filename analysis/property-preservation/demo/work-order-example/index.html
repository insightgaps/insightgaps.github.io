Contrast: the order that is HELD (FAKE)

WO-EXAMPLE-004 — SAMPLE-004, 404 Practice Avenue, Practicetown, Sample Client C, $250 sample debris removal — is HELD for a proof gap: its After set is missing the sample "cleared area" view, so the file does not prove the scope. The next action is a retake, not a submission. A held order is not a failed crew; it is an incomplete file. Fix the file first.

What this example teaches

  • A work order is a chain: authority → field → proof → money → cross-check. Break one link and the chain does not hold.
  • "Completed in the field" and "ready to submit" are different states. The demo keeps them apart on purpose.
  • The fastest audit question is always: what does the file prove, line by line? Not: how hard did the crew work?
