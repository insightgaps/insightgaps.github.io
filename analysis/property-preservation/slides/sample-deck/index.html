SAMPLE — How to add a slide deck

This is a sample deck entry, showing the shape of a real entry. It is not a real class, and it links to no real slide file.

  • Class: SAMPLE class
  • Date: 2026-01-01
  • Slide file: none — a real deck would link to its slide file here, for example a PDF in the vault's files folder, added as a file and rebuilt with the site.

To add a real deck, copy this file's frontmatter pattern into a new file in the same folder, change the title, class, date, and slide file link, write a short description in the body, rebuild, and the deck will be built as its own direct-link page. The Class Vault is currently closed and shows no slide list, so a deck is NOT listed there until the owner opens the vault. The Vault gate, when opened, is obscurity only, not security: slides are added by editing files plus a rebuild, there is no automatic listing mechanism.
