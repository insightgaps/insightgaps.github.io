Class Vault — currently closed

This vault is locked. No slide list is shown on this page, and no passcode appears in this page's source or anywhere else in this site's source. The vault stays closed until the owner sets a passcode before opening it.

Honest label, read this first: a gate on a static site is obscurity, not security. Hiding is not privacy, and a static-site gate is not a vault in the security sense. Even after the owner opens the vault, anyone with the direct link who knows the passcode can read the slides.

Do not put secrets, credentials, passwords, payment details, personal data, or sensitive material in this vault, ever. It is for class slides only — teaching material the owner is willing to have read by anyone who finds the direct link and the passcode.

How a deck is added (when the vault is opened)

Decks are added as files, then the site is rebuilt — see the How to add a deck page. There is no upload form, because a static site has no backend upload. A file added only in a browser is not saved to the site — it must be added as a file and rebuilt. No deck is listed on this page while the vault is closed.
