Class 1 — The Industry Behind the Work Order

FICTIONAL training material, except where a line is explicitly marked as real industry history. Every class opens with: "Everything in this class uses a fictional client and fictional rules. Real clients differ. The skill is reading the sheet in front of you."

  • One mental model: A work order is one link in a chain of responsibility, evidence, and money.
  • Exit skill: Tell the industry's full story (all five acts) AND map the system it produced.
  • Length: 30 minutes. Trainer narration about 10 minutes — a DELIBERATE exception to the 8-minute cap, by owner order, because Class 1 IS the whole story. The 8-minute cap is a design choice, not research.
  • This class does NOT use the spine case. It IS the whole story. Classes 2–6 use 60-second callbacks to the relevant act, never a retelling.

The 30-minute run — five acts, each a scene + pair work

Lessons

  1. A vacant property still has an owner, a record, and a chain of responsibility. "Empty" never means "nobody's problem."
  2. Scale without standards produces volume, not quality. When thousands of contractors flood in, the record — not the claim — becomes the only proof.
  3. Authority first. An action without authority is a liability, not a service. This is the rule Act 3 leaves behind, and it is the whole of Class 2.
  4. The rulebook on the order governs. Never assume one client's rule applies to another client's order.
  5. Judgment is the job. Machines may automate routine checks; exceptions, authority, and conflicting evidence stay human.

Rules for telling this story (trainer guardrails)

  • Every scene must end in a decision rule or it gets cut. No trivia, no dramatic statistics for their own sake.
  • Real history and fictional training material are never mixed in one breath.
  • Nothing flagged by the evidence check enters the story: no "largest" as fact, no filings-as-orders, no Jordan-as-national-rule, no ML 2016-02 as a current universal rule, no fee-chain ratio as fact, no AI human-share percentage, no unverified figure.
  • The earlier Gemini Class 1 (Collateral Paradox / WO-101) is a DIFFERENT Class 1 design from the same source material. This page follows the final selection (October 2025): Class 1 is the whole industry story. The WO-101 lockout material now lives in Class 2.

Workbook / tasks

  • Pre-read (flipped): glossary (8 terms, with Bangla glosses) + this class's run plan. No glossary lecture in class — it is a reference sheet.
  • In class: one-sentence cold-open answer (ungraded) · pair chain map on the whiteboard · one-sentence chain, spoken aloud, at retrieval.
  • Decision Log (unscored): first decision, confidence 1–3, reason, what changed. Learning made visible without scoring confidence.
  • Transfer bridge question to carry into Class 2: "A contractor says the house was vacant and changed the locks. How do you know he was allowed to?"

Slide deck

Exam preparation (what this class feeds)

  • Class 1 feeds the exam's concepts section and the "authority first" instinct behind every Critical Control: never approve, close, or invoice on missing or contradicted evidence. It does not, on its own, teach a scored skill — that is why Classes 2–6 exist.
