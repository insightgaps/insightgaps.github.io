Class 6 — The Judgment Layer (Operations War Room)

FICTIONAL training material. Spine case Sample Case, property 101 Sample Lane, Sampletown (synthetic training identifier). "Everything in this class uses a fictional client and fictional rules. Real clients differ. The skill is reading the sheet in front of you."

  • One mental model: A decision is only real when it can be defended: rule + evidence + next action.
  • Exit skill: Independently audit an unseen case, decide approve / hold / reject, and write it up.
  • Callback (60 seconds, not a retelling): Act 5, the future as a question — the job being hired for is the judgment layer.
  • Tools in this class: ALL of them, unaided — Five Questions, Epistemic Filter, Proof Test, Money Ladder, Triage Card, Update Line, 4-Line Forensic SBAR (STATE → EVIDENCE GAP → EXPOSURE → NEXT ACTION).

The 30-minute run

Same template as every class, with NO modelling at all: learners audit cold, defend, and get feedback only afterward. Anyone still needing a worked example in Session 6 is a hiring signal, not a teaching failure.

Lessons

  1. Severability: a file with five defects is not one verdict — it is five verdicts, line by line. A blanket hold hides the valid line; a blanket approval hides the defects. Audit each line, then decide the file.
  2. The 4-Line SBAR is the whole decision in miniature: STATE (what you decided) → EVIDENCE GAP (what is missing or contradicted) → EXPOSURE (what it costs if you are wrong) → NEXT ACTION (who does what, by when).
  3. Time pressure does not change the rules. A cutoff in 90 minutes changes the ORDER of work (valid, time-critical lines first), not the standard of proof.
  4. Decoys are part of the test. A case with only real issues teaches pattern-matching; a case with decoys teaches judgment. That is why the practice case below mixes both.

Case: Sample Order 5, Pre-Conveyance Final Audit (spine, fictional)

  • Setting: pre-conveyance final audit, 90 minutes to a fictional conveyance cutoff. Contractor packet claims a fictional total in the packet.
  • Line 1 — boarding (fictional citation in the packet): fully valid and time-critical — survives in full in the packet's scoring.
  • Line 2 — debris: claimed at a higher fictional volume than the actual fictional volume in the packet, with a recycled After photo from an earlier date. Audited volume is the packet's actual figure, not the claimed figure.
  • Line 3 — winterization re-check: gauge reads 0 PSI in the packet — the re-check does not prove the work.
  • Packet scoring (fictional, as in the packet): authorized invoice is the packet's surviving line amount only; the SBAR is graded 1 point per line (4 lines total); the full case carries a 10-point rubric in the packet.
  • Flagged, not taught as settled: the verified files flag that the war-room math must be line-item audited before use. This page therefore teaches the LINE STRUCTURE and the rubric, and marks the exact surviving total as to be line-item audited by the owner before teaching — the packet's total is not reproduced here as a settled teaching figure.
  • Anchor: the whole programme in one ABT sentence — authority, then evidence, then money, then queue, then judgment, in that order, every time.

Practice case — unseen, self-scored (TO BE COMPLETED BY OWNER)

  • Design (verified): a second, fully unseen practice case in the Birchwood style: 3 real issues + 2 decoys, self-scored against a shown rubric — the first time candidates meet a case cold before the exam.
  • Content: TO BE COMPLETED BY OWNER. The unseen case itself is NOT in the verified files on hand, so no placeholder case is written here. Writing a placeholder and calling it the practice case would teach an unvetted case as if it were vetted. The owner (or the trainer, under the owner's word) must supply the case, its rubric, and its decoy key before Class 6 is run with this element.

Workbook / tasks

  • Pre-read (flipped): full Sample Order 5 file with no guidance at all.
  • In class: cold verdict · cold-call defence · paired foil/practice audit · individual Update Line (≤25 words) · re-vote · full 10-point rubric applied to one line, individually.
  • Retrieval (closed-book): apply the full rubric to one line of an unseen case, in writing, with rule + evidence + next action.
  • After hiring reinforcement (hired staff only): Day 1 (10-minute replay with changed numbers) · Day 7 (15-minute closed-book mix + mini-case + one Update Line) · Day 30 (20-minute review of one real work item with a mentor — real work only after hiring, never in this class area) · Day 90 (30-minute independent mini-practical + QC-data review). Mentor budget: ≤1 hour per hire per quarter.
