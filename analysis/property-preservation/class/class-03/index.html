Class 3 — The Evidence Trial

FICTIONAL training material. Spine case #EPCS-8841, property 14 Oakfield Street, Maple Heights, OH (synthetic training identifier). "Everything in this class uses a fictional client and fictional rules. Real clients differ. The skill is reading the sheet in front of you."

  • One mental model: A claim must be supported by evidence relevant to the exact requirement being judged.
  • Exit skill: Sort every file item into verified fact / unverified claim / missing prerequisite / contradiction.
  • Callback (60 seconds, not a retelling): Act 3's documentation turn — date-stamped, labeled photos as the standard that arrived with the reckoning.
  • Tools in this class: the Proof Test (PLACE / TIME / SCOPE / CLARITY) + the Epistemic Filter + the integrity rule (never change, backdate, crop to hide, or invent evidence).

The 30-minute run

Same template as every class: cold verdict → cold-call defence → Socratic pressure → paired foil audit → re-vote + expert reveal → transfer bridge. Scaffolding in Sessions 3–4: trainer models only the first step; learners audit the rest; coaching on errors only.

Lessons

  1. A photo proves only what it shows — place, time, scope, clarity. A clear photo of the wrong house proves nothing about this house. A photo of this house at the wrong time proves nothing about this visit.
  2. Premature closure is the trap: thumbnail scanning → confirmation bias → search satisficing. The counter-move is Landmark-First Reverse Auditing: match landmarks first, then read the claim.
  3. Three-point disconfirmation checklist: Anchor Match (does the anchor in the photo match this property?) · EXIF/Season Match (does the timestamp and season match the claimed date?) · Landmark Overlap (do the landmarks overlap, or was the photo taken elsewhere?).
  4. Defects hide in three places: recycled photos, metadata mismatches, and crops that hide what was NOT done. All three appear in this class's case.
  5. Integrity is non-negotiable: never change, backdate, crop to hide, or invent evidence. A flag for proposing to alter/backdate/invent evidence goes to structured review in the exam.

Case: WO-103 (spine, fictional)

  • Claim: roof tarp + exterior debris, contractor claims a fictional amount in the packet ($800 in the Gemini packet summary).
  • Three hidden defects (fictional, as in the packet): (1) recycled tarp photos from a house 9 miles away — shingle/chimney mismatch; (2) EXIF timestamp discrepancy on the Before photo; (3) cropped After photo hiding the uncleaned driveway.
  • Anchor: a photo proves only what it shows — place, time, scope, clarity.
  • Foil — WO-103B, rear-door boarding (fictional): clean file → GREEN — approve the fictional invoice/payout amounts in the packet. Same file shape, opposite verdict. That contrast IS the lesson.

Workbook / tasks

  • Pre-read (flipped): WO-103 packet + Alpha-1 §3 (Photo & Metadata Standards) + one question: "What is your verdict, and what single fact decides it?"
  • In class: cold verdict · cold-call defence · paired foil audit · individual Update Line (≤25 words) · re-vote.
  • Retrieval (closed-book): run the Proof Test on one unseen photo: PLACE / TIME / SCOPE / CLARITY, one line each.
  • Annotated-diagram task (recommended photo medium, pending owner decision): annotate a diagram of the photo logic — arrows, circles, "look here" — rather than memorising stock photos. Diagrams teach the looking skill.
