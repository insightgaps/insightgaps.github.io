Class — Instructor Guide (SUPPLEMENTARY)

SUPPLEMENTARY. This page is practice guidance for running the class. It does not set an exam answer, a cut-score, a schedule, a hiring decision, or a client rule. Verified core content is in the six class pages and the exam page; anything here that disagrees with those pages loses.

Before the first session

  • Read the Class hub pending-decisions box. Do not promise learners an exam length, cut-score band, schedule format, or photo medium — none of those is decided in the verified files.
  • Open with the same sentence every class: "Everything in this class uses a fictional client and fictional rules. Real clients differ. The skill is reading the sheet in front of you."
  • Prepare the foil case cold. Do not teach the foil's verdict in advance — the learning is in the argument, not the answer.
  • Have the room tools visible: Five Questions, Proof Test, Money Ladder, Triage Card, Decision Log, Update Line (25 words or fewer). See Checklists + Templates.

Running a 30-minute session (the template, and what to protect)

  • 0:00–0:03 cold verdict on an unseen file · 0:03–0:08 cold-call defence · 0:08–0:15 Socratic pressure · 0:15–0:23 paired live audit (the foil) · 0:23–0:27 re-vote + expert reveal · 0:27–0:30 transfer bridge.
  • Cutting rule: cut pair discussion first, then the consequence reveal. NEVER cut the re-vote + expert reveal or the transfer bridge.
  • Trainer talks at most about 8 minutes per session (Class 1: about 10, by deliberate owner order). If you are talking more than that, you are lecturing, and this programme is not a lecture programme.
  • Scaffolding fades: Sessions 1–2, model the full audit aloud, then coach. Sessions 3–4, model only the first step. Sessions 5–6, NO modelling — learners audit cold and defend.

When learners disagree (this is the point)

  • Praise a reasoned wrong answer. Bluffing is the only failure. Verdicts and reasoning are judged, never accent, grammar, or speed of speech.
  • When two learners disagree, do not settle it by authority. Make each one state: rule + evidence + next action. The one who cannot state all three has not finished, even if their verdict happens to be right.
  • If the room splits on a foil, let the split stand until the re-vote. The expert reveal lands harder after a real disagreement than after a polite nod.
  • Never read bullet points aloud. Never let a learner read bullet points aloud either — they decide, they defend, they write.

After the session

  • Learners write their Decision Log entry the same day (unscored). A decision without a written rule + evidence + next action does not count as learned.
  • Use the Study Guide retrieval plan between sessions — retrieval first, re-reading last.
  • Post-hire reinforcement (from Class 6): Day 1, Day 7, Day 30, Day 90. A class that ends on the last day is a class that fades; the reinforcement schedule is part of the programme, not an afterthought.
  • If a learner asks about a real client, a real portal, or a real rate: stop. This class uses fictional material only. Real-client questions belong in the real system, with the real sheet in front of you — never answered from class examples.

Common instructor mistakes (supplementary, from the programme's own rules)

  • Teaching Class 6's war-room math before its line-item audit is done — the Sample Order 5 math is marked pending for that reason. Do not teach it as settled.
  • Merging the two exam proposals into one — the reconciled proposal and the alternative are presented separately on the exam page, on purpose.
  • Presenting a practice case as a real case, or a supplementary checklist as an official rule. Label every supplementary page out loud, not just in its heading.
  • Running a session that cannot run with the projector off. Slides are the smallest part of the build. Workbook first, trainer guide second, slides last.
