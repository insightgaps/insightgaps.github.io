Study Guide — How to Learn This Programme

SUPPLEMENTARY study guide. It tells you how to use the class hub, not what the exam will ask. Exam rules live on the exam page.

The one rule of studying here

Retrieve, don't re-read. Every class opens and closes with retrieval for a reason: a verdict written from memory, then corrected, sticks; a page re-read does not. Before each class, write your verdict and its one deciding fact WITHOUT looking at the answer. After each class, write it again, cold, the next day.

Week-by-week study plan (supplementary — adapt to the owner's schedule, which is not decided)

  • Night before each class: read the next work order + rule sheet + the one question ("What is your verdict, and what single fact decides it?"). Write the verdict. Bring it.
  • In class: defend it, lose it, or keep it — all three are learning, if you can name the fact that changed it.
  • After class, same day: re-write the Update Line (≤25 words) and the SBAR for the case you got wrong. That rewrite is the study.
  • Cumulative retrieval: Classes 2–6 open with a 60-second cumulative retrieval from earlier classes. If you cannot retrieve Class 2's rule in Class 5, go back to the reference page and re-audit one old case cold — do not just re-read the rule.
  • Fading: Sessions 1–2 model the audit aloud; Sessions 3–4 model only the first step; Sessions 5–6 model nothing. If you still need a worked example in Session 6, that is information, not failure — bring it to the trainer before the exam, not after.

Post-hire reinforcement (hired staff only, from the verified programme)

  • Day 1: 10-minute replay of the spine case with changed numbers.
  • Day 7: 15-minute closed-book mix + mini-case + one Update Line.
  • Day 30: 20-minute review of one real work item with a mentor. Real work only after hiring — never in this class area.
  • Day 90: 30-minute independent mini-practical + QC-data review.
  • Mentor budget: ≤1 hour per hire per quarter. Anti-leakage: parameter swapping (same structure, new numbers) every quarter, so no cohort hands the next one the answers.

How experienced learners should use this hub differently

Do not re-take the beginner path. Go straight to the advanced edge cases and the practice cases, audit them cold, and compare your verdict to the outcome. If your verdict matches but your rule differs, the rule difference is the learning. If you finish all practice cases without a single surprise, tell the trainer — the next cases should be harder, not more numerous.

What NOT to do while studying

  • Do not memorise fee schedules, portal steps, or the spine case's answers. The exam uses a different fictional rule sheet (Beta-2) precisely to punish memorisation and reward rule-reading.
  • Do not study by re-reading slides. Slides are the smallest part of the build. Study by verdict, by audit, by Update Line.
  • Do not ask "does everyone understand?" of yourself. Ask: "What is my verdict, and what single fact decides it?" If you cannot answer, that is the study topic.
