Class — Start Here

TRAINING ONLY — every case, client, address, amount, and rule sheet in this class area is FICTIONAL training material, unless a line is explicitly marked as real industry history. Real clients differ. The skill is reading the sheet in front of you.

Pick your path. Do not start in the middle — the programme is built in order, and Class 6 only pays off if Classes 2–5 came first.

If you teach today

Start with Class 1 only, projector off, no slides required. Do NOT present exam length, cut-scores, schedule, photo medium, slide text, the Sample Order 5 total, or the unseen Birchwood case as final — all are marked to be completed / decided by owner on the class hub.

Path 1 — New to preservation

You have never done US property preservation work. Start here, in order:

  1. Class 1 — The Industry Behind the Work Order — the whole story, five acts. This is why the work exists. Do not skip it.
  2. Class 2 — The Permission Gate — no action without authority. Learn the Five Questions here; they run through every later class.
  3. Class 3 — The Evidence Trial — the Proof Test: PLACE / TIME / SCOPE / CLARITY.
  4. Class 4 — The Money Trail — claimed ≠ approved ≠ paid. Learn the Money Ladder.
  5. Class 5 — The Queue Under Pressure — the Triage Card, money clock vs portal clock.
  6. Class 6 — The Judgment Layer — the unaided war room. This is the rehearsal for the exam.
  7. Exam + interview — read the pending-decisions box first: exam length, cut-scores, schedule, and photo medium are NOT decided in the verified files.

Between classes, use the Study Guide (retrieval-first, fading scaffolding) and the Checklists + Templates.

Path 2 — Experienced in preservation

You have done this work. You will not learn much from being told what a work order is — start where it breaks:

  1. Advanced Edge Cases — For Experienced People — ambiguous orders, photo failures, submission rejections, renumbered orders, loss-reason discipline, datestamp/QC traps. Verified core is marked distinct from practice guidance throughout.
  2. Practice Cases (FAKE) — four complete cases with verdicts. Decide before you read the verdict.
  3. Class 6 — The Judgment Layer — audit the unseen case cold, decide approve / hold / reject, and write it up.
  4. Then, if you want the full system: go back to Class 1 and read it as a system map, not a beginner lesson — the five acts explain why the edge cases keep happening.

30-minute self-study path (one session, no trainer)

  1. Read the Find It Fast — Reference Index — 2 minutes, find the tool you need.
  2. Take the Demo Guided Tour — 10 minutes, fake data only.
  3. Decide one Practice Case cold, then read its verdict — 15 minutes.
  4. Write your decision in the Decision Log format — 3 minutes. If you cannot defend it in one sentence (rule + evidence + next action), it is not a decision yet.

If you are running the class

Read the Instructor Guide (supplementary) before your first session, then run from the Class hub. The hub holds the programme at a glance, the delivery system, the case spine, and the pending decisions — read the pending-decisions box before promising learners anything about exam length, cut-scores, schedule, or photo medium.
