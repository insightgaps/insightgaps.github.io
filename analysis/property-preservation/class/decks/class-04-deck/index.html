Slide Deck — Class 4 — The Money Trail

Deck for Class 4. FICTIONAL training material. Slides are the smallest part of the build — this class must run with the projector off.

  • Class: Class 4
  • Slide file: none yet — a real slide file (for example a PDF) is linked here only when the owner adds it as a file and rebuilds. Do not invent a file link.
  • Design: Deep Slate Navy / Off-White canvas, Charcoal / Steel Blue ink, GREEN / AMBER / RED status, 45-word maximum per slide, source-citation footer on every slide.

The six slides — structure and takeaway only

Slide Structure Takeaway
1 Recall + cold open The question this class answers, in one verdict: Approve / Hold / Reject + the one fact it stands on.
2 Layer 1 model The class's one mental model, stated in one sentence.
3 Historical anchor The history that explains why this model exists — the Money Ladder and volumetric math, spine case WO-104.
4 Layer 2 + worked audit The model applied to the class case, step by step, with the rule and the exact evidence named.
5 Contrasting foil The near-identical case with one decisive variable flipped — same shape, opposite verdict.
6 Retrieval check + anchor Closed-book retrieval, then the class anchor in one sentence.

Exact on-screen slide text: TO BE COMPLETED BY OWNER. The storyboard file's exact texts are not in the verified files on hand, so no slide text is invented here. To complete a deck: add the slide file as a file, write the exact text into the deck file following the 45-word rule, rebuild, and check the link.
