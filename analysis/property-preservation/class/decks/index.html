Slide Decks — All Six Classes

Reading these decks is open via direct link. Adding or editing a deck is owner-only: decks are added as Markdown files, then the site is rebuilt — see the How to add a deck page. There is no upload form, because a static site has no backend.

Slides are the smallest part of the build, not the first. Every class must run with the projector off. If it cannot, it is a lecture with pictures, not a graduate session.

Deck architecture (identical for every class, from the verified storyboard design)

  1. Recall + cold open (00:00–04:00)
  2. Layer 1 model (04:00–07:00) — in the Presentation Plan's 30-minute template, the model block runs to about 0:08; the storyboard timing above is the Gemini 28-minute clock, which sums to 28 minutes with a 2-minute buffer whose placement is ambiguous in the verified files. Timing discrepancy flagged, not smoothed over — trainer must reconcile the clock before running.
  3. Historical anchor (07:00–10:00)
  4. Layer 2 + worked audit (10:00–17:00)
  5. Contrasting foil (17:00–25:00)
  6. Retrieval check + anchor (25:00–28:00)

Visual design system (from the verified storyboard design): canvas Deep Slate Navy / Off-White; ink Charcoal / Steel Blue; status GREEN / AMBER / RED; headers 28–32pt, body 18–20pt, mono 16–18pt; 45-word maximum per slide; source-citation footer rule on every slide.
