The five work-order types — requirements summary

Every requirement below is typical — always check the order. The order's rulebook governs.

Grass Cut + Recut (Session 6)

Before photos of the full lot; cut + trim + edge; after photos wide (whole lot) + close (edges); date-stamps where the order's rulebook requires them; recut diary set for the next visit. Teams: Field Crew cuts; Vendor Manager dispatches + confirms; Processor proves + invoices; Client Manager submits + tracks the cycle. Safety: eye protection, check the lawn for hidden debris and wires before cutting, never cut toward people or the road. SAY: "Grass is the house's face."

Initial Secure (Session 6)

Every exterior lock changed; lockbox code set exactly as the order states; each broken or weak entry boarded; a photo of every lock and every board, before / during / after, labelled. Permission first — occupancy uncertain = HOLD + escalate, no exceptions. Teams: Field Crew secures; Vendor Manager owns the permission gate; Processor proves every lock and board; Client Manager submits. Safety: never enter a house with occupancy signs, broken glass underfoot, or animals inside; if anything feels occupied or unsafe, STOP + report. SAY: "Secure is not a job. It is the permission slip for every job after it."

Winterization (Session 7)

Water shut at the main; every line drained; antifreeze in every trap + toilet; water heater handled exactly as the order states; notice posted; BEFORE shots: meter, shutoff, each fixture. Hard rule: system will not hold pressure, or a valve is stuck → do NOT fake it — HOLD + report. A failed test is information, not failure. Teams: Field Crew winterizes; Vendor Manager dispatches + owns the HOLD rule; Processor proves every fixture; Client Manager submits. Safety: hot water can scald, a pressurised line can burst, and antifreeze is poisonous — never taste it, never leave it where children or animals can reach it. SAY: "Winterization is the cheapest job that prevents the most expensive damage."

Debris Removal / Trash-Out (Session 7)

Before photos of EVERY room; remove only what the order covers (never personal property it does not cover); honest cubic yards — length × width × height in feet ÷ 27 (synthetic example, labelled: 9 × 6 × 3 ft = 162 cu ft ÷ 27 = 6 CY; a 15 CY bill for that pile fails the math); after photos empty + swept. Teams: Field Crew removes + measures; Vendor Manager dispatches; Processor checks the math; Client Manager submits. Safety: lift with legs not back, gloves for sharp objects, dust mask where mould or dust is heavy, and never remove personal property the order does not cover. SAY: "Debris is where honesty is measured — literally, in cubic yards."

Inspection / Initial Services (Session 7)

Every room photographed; occupancy signs noted (lived-in signs = STOP + report, do not proceed); damage noted room by room; report written the same day. The report IS the product — the report is the "after" of an inspection. Teams: Field Crew inspects; Vendor Manager dispatches; Processor proves the report; Client Manager submits. Safety: never enter an unsafe structure, never climb a failing stair, and if occupancy signs appear mid-inspection, STOP + report; the report is never worth a person. SAY: "An inspection does not fix anything. It tells the truth about everything."

Photos list

Every required shot, per type, in one list: Photos List — grass (before full lot, during crew at work, after wide + close); secure (every lock and every board, before / during / after, labelled — the strictest proof); winterization (BEFORE meter / shutoff / each fixture, during each step, after dry fixtures + antifreeze + notice posted); debris (before every room, during cleanout + measured pile, after every room empty + swept); inspection (during every room, after = the written report).

Four photo rules, travelling with every set: no photo = no proof; defective shots (blurry, dark, missing-room, missing-fixture, wrong-property, unlabelled) go back to the field; date-stamps per the order — always check the order, and if unclear, date-stamp anyway; sets are illustrative only — public photographs of the work type, not job photos, not one job's sequence, never real job photos.

Money ladder — summary

BID → ALLOWABLE → APPROVED → INVOICED → PAID. Each step is a different person's decision; money is lost between every pair, and every loss has an owner.

Synthetic worked ladder, labelled: bid 1,000 → allowable 800 (lost 200: $120 unallowable + $80 unproven, owner the Processor) → approved 700 (lost 100: bid/approval, owner the Vendor Manager's bid + approval) → invoiced 700 (lost 0) → paid 550 (lost 150: $60 unfixed rejection + $50 short-paid + $40 adjustment, owner the Client Manager with the Processor).

Do not confuse this teaching ladder with the fictional $100 → $55 contractor-chain funnel: the funnel is a made-up illustration of fee compression, never a fact, and it is not this ladder.

Loss reason codes, one on every loss: REJECTED (rejected and never fixed), SHORT-PAID (paid below invoice), UNALLOWABLE (scope outside the rulebook), ADJUSTED (absorbed by a property-level adjustment), CHAIN-PAID (paid under a follow-up WO at the same property), UNEXPLAINED (no reason found yet — a queue, never a final answer).

Invoice verdict, worked (synthetic, labelled): $400 invoice — grass $60 photos good; secure $150 missing one lock photo; debris $150 billed 10 CY vs 6 measured; $40 television line the order never listed → FIX at the Allowable rung, owner the Processor; Client Manager holds submission until the fix lands.

Capstone pass standard (program standard, teacher may adjust): pass = name all 4 failures (permission uncertainty, proof gap, winterization test not honestly closed, money math) AND the Update Line passes all 4 checks; revise-and-retry = 3 of 4 on either side; not yet = fewer than 3 of 4.

Guards — never teach these

  • Jordan as a national ban (Washington law only, 7 July 2016; $17M settlement, final approval 3 May 2019, taught as the settlement, not the ruling).
  • The $100 → $55 funnel as fact (fictional illustration only).
  • The $5,000 cap as all-inclusive or current (2016 figure, FHA-only; debris, grass, boarding, inspections, pool securing, sump pumps, demolition, registration fees, and utilities are NOT counted in the cap per the current handbook schedule; 7 years covers the Claim Review File, not photos as a standalone rule).
  • Filings as work orders; a combined in-foreclosure + REO number as REO alone; vendor forecasts as facts; real job photos as teaching photos.
