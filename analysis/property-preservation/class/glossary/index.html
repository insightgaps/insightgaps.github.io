Glossary — Supplementary Study Aid

SUPPLEMENTARY study aid, not verified exam content and not an official curriculum document. These are plain-English working definitions for terms used in the classes, written so a learner can look a term up in seconds. If a rule sheet on a real order says something different, the order's rule sheet governs — never this glossary.

  • Work order (WO): an instruction to do a defined job at a defined property, with a scope, a price rule, and a proof requirement. A work order is one link in a chain, not the whole job.
  • FTV (First Time Vacancy / initial visit): the first visit that establishes whether a property is vacant, using the rule sheet's occupancy test — never a single signal alone.
  • PCR (Property Condition Report): the report of a property's condition, with photos, that a later decision is judged against. A PCR is only as good as its photos and its dates.
  • Allowable: the maximum amount a rule sheet allows for a defined job. Claimed above the allowable, without a documented approval code, is a Critical Control flag.
  • Approved: the amount a reviewer has actually approved after checking scope, proof, and allowance. Approved is not the same as claimed, invoiced, or paid.
  • Invoiced / Paid: invoiced is the amount billed after approval; paid is the amount actually received. Billed ≠ earned; only APPROVED becomes PAID.
  • Curtailment: a reduction in payment because a requirement was missed, late, or unproven. In class material, curtailment figures are fictional packet illustrations, never real curtailments.
  • Reconveyance: returning a property / loan file because a requirement (often mortgagee neglect) was not met. Taught here only as a consequence category, never as legal advice.
  • Mortgagee Neglect: failure by the party responsible for a mortgaged property to meet a required standard, where the cost is then not reimbursable. Borrower Waste is different: damage caused by the borrower, reimbursable only if documented at the first visit.
  • REO (Real Estate Owned): a property owned by a lender/servicer after foreclosure. Post-foreclosure REO authority is different from pre-foreclosure securing authority — that difference decides Class 2.
  • Triage: ordering competing work by deadlines + consequences + dependencies + the next action actually available — not by portal due date alone, and not by who shouts loudest.
  • SBAR (4-Line Forensic SBAR): STATE → EVIDENCE GAP → EXPOSURE → NEXT ACTION. The whole decision in four lines.
  • Update Line: a decision in 25 words or fewer: ORDER: DECISION. Gap (rule). Next step, owner, time.
  • Proof Test: PLACE / TIME / SCOPE / CLARITY — the four questions every photo must pass.
  • Money Ladder: ALLOWABLE → BID → APPROVED → INVOICED → PAID — five different stages, never collapsed into one number.
  • Critical Control (CCV): a control whose breach sends a case to structured review. A CCV is a CCV — there is no "minor CCV" in this programme.
  • Foil: a near-identical case with one decisive variable flipped, used to test whether a learner's verdict follows the rule or the surface of the case.

What this glossary does NOT do: it does not replace the class rule sheets, it does not define any real client's rules, and it is not taught as a lecture in class — it is a one-page reference, used before class and during revision.
