Operations system — feature showcase

This section is a feature showcase for a property-care operations system. It contains no real data: no real dataset, no real work-order numbers, addresses, client names, amounts, crew names, or payment details. Every example on every page in this section is labelled SAMPLE and uses fictional sample values that cannot be mistaken for a real job.

Hiding is not privacy. Anyone with a direct link can open these pages, and the files remain in the public repository. Do not put secrets, credentials, or sensitive material here.

What the system does

  • Property tracking, keyed by address — one property, one record, matched by address first, never by work-order number alone.
  • Photo QC and datestamps — before, during, and after photo sets, checked, flagged, and datestamped by the rules of the receiving system.
  • Reconciliation and loss-reason discipline — every loss carries a mandatory reason code; unexplained losses are a queue driven to zero, never a closed book.
  • Submission-queue discipline — complete, then report the finished state, then owner cross-check, then submit only on the owner's word. One job at a time, never on a green light alone.
  • Class — the whole hiring-training programme — six 30-minute preservation-only classes, exam preparation, slide decks, plus supplementary reference material (glossary, checklists, practice cases, advanced edge cases, find-it-fast index). Reading is open via direct link; adding/editing is owner-only. FICTIONAL training material only.
  • Demo — operations system clone, ALL DATA FAKE — Live Ops, Money, Properties, Crew, Submission Queue, and Meeting Brief, cloned in structure only, with a small fake seed. No submit action anywhere. For class/training only.
  • Class Vault — currently closed and locked, for ADDING/EDITING class slides only (owner-only). No slide list is shown, and no passcode appears in source. The gate, when opened, is obscurity, not security: see the Vault page for the honest label. Class READING is via the class hub link above, not through the locked Vault.
