# Antigravity Instructions

Before making any modification in this repository:

1. Read `START_HERE.md`.
2. Read `AGENTS.md`.
3. Read every governance document listed in `AGENTS.md`.
4. Submit the pre-flight report required by `START_HERE.md`.
5. Wait for human owner approval before editing site files.

Use the same safety rules as other coding agents:

- Do not delete investigations.
- Do not remove trust pages.
- Do not change architecture, schemas, or design tokens without explicit approval.
- Do not push to production without explicit human owner instruction.
