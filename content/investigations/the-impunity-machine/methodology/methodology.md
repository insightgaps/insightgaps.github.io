# BD-INV-002 Methodology

This visual report is built from the evidence table embedded in the investigation page and the cited public-source figures named in the report narrative.

Core figures used by the visual include One-Stop Crisis Centre outcomes from 2001-2024, BRAC justice outcome figures, PBI case-closure figures, UNFPA lifetime intimate-partner-violence estimates, police pending-case figures, NFDPL DNA processing figures, and comparative conviction-rate references used in the report.

Claims are presented as evidence-tiered findings. The interactive export on the report page downloads the key evidence rows used by the visual.
