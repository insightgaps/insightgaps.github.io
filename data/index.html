Dataset Schemas & Field Dictionaries
Mapped Sites CSV Schema (BD-INV-003_LeadBelt_MasterDataset_v5.csv):
  • i: Unique Site ID (e.g. BD-4591)
  • d: Division (e.g. Dhaka)
  • n: Site Type / Name (e.g. ULAB Recycling Factory)
  • th: Thana / Upazila name (e.g. Rosulpur)
  • p: Soil lead concentration (PPM)
  • v: Contamination tier classification (e.g. critical, severe)
  • la, lo: Latitude and Longitude coordinate points
  • sc: Count of school campuses within 500 meters
  • cm: Great-circle distance to the closest school in meters
  • cn: Name of the closest school campus
  • sat: Boolean indicating if active smelting operations are visually visible in satellite imagery
  • tp: Verification audit verdict note
OSM School snapshot GeoJSON (osm_schools.geojson):
  • type: GeoJSON Feature type
  • geometry: Coordinate points (longitude, latitude)
  • properties: Feature tags from OpenStreetMap:
    • id: Historic OSM node, way, or relation ID
    • name: Name of school (transliterated or English)
    • amenity: Set to "school"
